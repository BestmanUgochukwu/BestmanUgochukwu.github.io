What I Built — 4 Assignments

The Full Pipeline

1

Self-Hosted Azure DevOps Agent

Registered an Ubuntu VM as a self-hosted build agent with Azure DevOps. Debugged SSH key mismatches, wrong usernames, changed download URLs, and PAT token scope issues. When it finally showed Online — I understood that infrastructure is never just configuration. It is problem solving.

2

Automated Static Site Deployment via SSH

Pipeline: Git commit → Azure DevOps → CopyFilesOverSSH → Ubuntu VM → Nginx → Browser. Discovered that Ubuntu cloud images disable password auth through override files in /etc/ssh/sshd_config.d/ — even when the main config allows it. Key lesson: always check override config files, not just the main config.

3

Multi-Stage React App Pipeline

Three stages: Build (npm install + npm run build), Test (npm test), Deploy (CopyFilesOverSSH to /var/www/html). You never deploy source code. You deploy artifacts. Every commit to main automatically builds, tests, and deploys the React app — zero manual intervention.

4

Production IaC — Terraform + App Pipeline

Two-repo model: infra-epicbook/ (Terraform) and theepicbook/ (Application). Terraform created the Resource Group, VNet, Subnet, NSG, Public IP, NIC, and Ubuntu VM automatically. App pipeline then deployed Node.js, MySQL, Nginx, and started the app as a systemd service.

The Two-Repository Model

Infrastructure code and application code change at different rates. A network config might change once a month. App code might change ten times a day. Separating them allows different teams to deploy at different cadences — standard enterprise DevOps practice.

Service Principals Are the Backbone of Automation

Azure AD app registrations, client secrets, and role assignments working together. Azure's permission model has multiple layers — subscription roles, ABAC conditions, and directory permissions can all independently block you.

Errors Are the Curriculum

Every failed pipeline run taught something specific. Permission errors taught Azure's security model. Connection errors taught networking. Deprecated package warnings taught dependency management.
