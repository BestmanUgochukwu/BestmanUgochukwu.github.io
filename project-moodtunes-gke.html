What I Built

Built and deployed the MoodTunes React web application on Google Kubernetes Engine — a fully managed Kubernetes service on GCP. The deployment includes automatic HTTPS via Let's Encrypt, NGINX Ingress for traffic routing, automated container builds with Cloud Build, and image storage in Google Container Registry.

Key Components Explained

Technical Breakdown

Google Kubernetes Engine (GKE)

GKE manages the Kubernetes control plane automatically — no manual etcd management, no API server maintenance. The cluster auto-upgrades and scales worker nodes based on workload demand. This is production-grade Kubernetes without the operational overhead of self-managed clusters.

NGINX Ingress Controller

Instead of exposing each service directly to the internet, NGINX Ingress acts as a single entry point for all traffic. It routes requests to the correct backend service based on hostname/path rules, handles SSL termination, and enforces HTTP-to-HTTPS redirects — all from one controller.

Let's Encrypt with cert-manager

Deployed cert-manager inside the cluster to automatically provision and renew TLS certificates from Let's Encrypt. Certificates are stored as Kubernetes Secrets and mounted by the Ingress controller — HTTPS is automatic and maintenance-free.

Google Container Registry (GCR) + Cloud Build

Every code push triggers a Cloud Build pipeline that builds the Docker image and pushes it to GCR — Google's private container registry. The Kubernetes Deployment then pulls the new image from GCR during rollouts, ensuring the cluster always uses authenticated, controlled images.

Lessons Learned

What I Took Away

Kubernetes Orchestrates So You Don't Have To

Kubernetes handles pod restarts, rolling updates, health checks, and traffic routing automatically. The cluster breathes — expanding when stressed, contracting when calm — without manual intervention.

Ingress Is the Right Pattern for Production

Exposing individual services via LoadBalancer type creates one cloud load balancer per service — expensive and unmanageable at scale. NGINX Ingress consolidates all external traffic through one entry point with path-based routing.

Automate Certificate Management

Manual TLS certificate management is a reliability risk — expired certificates take down HTTPS silently. cert-manager with Let's Encrypt automates renewal well before expiry, eliminating this failure mode entirely.
